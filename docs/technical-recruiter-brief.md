# Technical Recruiter Brief

## What This Portfolio Shows

This portfolio shows BI consulting work in a simple way.

It has:

- public official data;
- a dashboard site;
- KPI cards;
- filters;
- charts;
- tables;
- a decision score;
- SQL examples;
- three business cases.

## What To Review First

| Item | Why It Matters |
|---|---|
| `site/index.html` | Shows the full dashboard and portfolio UX |

| `site/data/global_tech_financials_2024.csv` | Shows the official public dataset used in the dashboard |
| `cases/` | Shows how the same BI work can help companies and governments |

## Main Technical Points

1. The dashboard loads a CSV dataset.
2. It calculates revenue, net income, margin, technology intensity, and productivity.
3. It creates a decision score using clear weights.
4. It ranks companies by the score.
5. It shows the result with filters, KPI cards, bars, a table, and simple insights.

The portfolio is not only a website. It is a small BI product.
