## Secondary Titles

| Title | Use When |
|---|---|
| Senior BI Developer | When Power BI/Tableau build is central |
| Dashboard Developer | For fast hiring and contract work |
| Reporting Automation Specialist | When the role focuses on replacing manual Excel/reporting |
| Business Intelligence Analyst | For lower-barrier applications |
| Data Analyst | Use only when the description emphasizes BI, dashboards, SQL, insights |
| BI Architect | Use when the role is not engineering-heavy |
| Analytics Engineer | Use when the role focuses on semantic models, metrics layer, dbt, BI, and KPI reliability, not heavy pipeline engineering |
