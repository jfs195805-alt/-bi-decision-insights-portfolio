# Certification Roadmap

You already have the two most important BI credibility signals:

- Microsoft PL-300: Power BI Data Analyst
- Tableau Certification

The next certifications should move you from dashboard specialist to senior consulting profile.

## Recommended Order

| Priority | Certification | Why It Matters |
|---:|---|---|
| 1 | Microsoft DP-600: Fabric Analytics Engineer Associate | Best upgrade from Power BI into modern Microsoft analytics and semantic modeling |
| 2 | IIBA-CBDA: Certification in Business Data Analytics | Strong signal for consulting, business analysis, insights, and decision support |
| 3 | Microsoft AI-900: Azure AI Fundamentals | Fast, light AI credibility without repositioning as ML or LLM engineer |
| 4 | Looker / BigQuery skill badges | Useful for Google Cloud analytics roles |

## Short-Term Hiring Stack

For Dubai, Abu Dhabi, and remote international roles:

1. PL-300
2. Tableau Certification
3. DP-600
4. Portfolio with three executive dashboard cases
5. LinkedIn in English with consulting positioning
