# Portfolio Website

This folder contains a recruiter-ready BI and analytics engineering portfolio site.

## What It Demonstrates

- Executive dashboard design
- KPI governance
- Data storytelling
- Analytics engineering
- Power BI / Tableau / Looker positioning
- SQL / Python / BigQuery / Snowflake / AWS keyword alignment
- Public official data source methodology

## How To Open Locally

From this folder, run a simple local server:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
